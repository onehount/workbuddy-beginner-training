# 教学对象

---

## 一、画像

| 维度 | 设定 |
|---|---|
| **身份** | 第一次接触 WorkBuddy 的新员工 |
| **编程基础** | 不要求，且默认为零 |
| **AI 认知** | 不要求了解 Agent、模型或自动化原理 |
| **电脑能力** | 能完成一般电脑文件操作（新建文件夹、复制文件、打开 Office） |
| **动机** | 希望快速把 WorkBuddy 用于日常办公任务 |
| **人数** | 单场 15–40 人 |
| **形式** | 讲师讲授，学员听讲，不现场操作 |

---

## 二、他们已经会什么

讲课时可以直接使用、无需解释的概念：

- ✅ 文件、文件夹、路径、扩展名
- ✅ Word / Excel / PowerPoint 的基本使用
- ✅ 复制粘贴、另存为、导出 PDF
- ✅ 微信、企业内部通讯工具
- ✅ "上传附件"这个动作
- ✅ 会议纪要、工作总结、通知这些**文体本身**

---

## 三、他们不会什么（讲师必须避开的坑）

以下概念**必须解释或直接避免**：

| 术语 | 处理方式 |
|---|---|
| Agent / 智能体 | 改说「一个会自己分步骤干活的助手」 |
| Prompt / 提示词 | 首次出现时说「提示词，就是你发给它的那段话」 |
| 上下文 / Context | 改说「它这次任务里能看到的全部信息」 |
| 幻觉 / Hallucination | 改说「它会编造看起来很像真的、但其实不存在的内容」 |
| Token | **完全不提** |
| 模型 / 参数 / 微调 | **完全不提** |
| API / 接口 / 调用 | **完全不提** |
| 工作流 / Workflow | 改说「一套固定的做事顺序」 |
| 迭代 | 改说「改一版、再改一版」 |
| 结构化 | 改说「按固定格式整理好」 |

## 四、他们真实的痛点（第一章要打中的）

课程第一章「新员工常见办公困境」页，讲的应该是这些：

### 痛点一：不知道从哪下手

> 领导说"把上个月市场情况整理一下"，材料在 5 个人手里，格式各不相同，第一步该干嘛？

### 痛点二：机械劳动占了大半时间

> 真正动脑的部分 20 分钟，剩下 3 小时都在：从会议录音里抄内容、把表格数字誊到文档、统一字体字号、导出成 PDF 再转成 PPT。

### 痛点三：怕做错，更怕不知道自己做错了

> 纪要里把"建议"写成了"决定"，把 A 的活写成了 B 的责任 —— 发出去之前根本没人告诉你哪里有问题。

### 痛点四：用过 AI，但结果不能直接用

> 让 AI 写工作总结，它写得很流畅，但里面的数字是编的，活动名称是编的，最后还得自己重写一遍。

> 💡 **讲师注意**：第四个痛点是全场的钩子。绝大多数学员试过 AI，然后放弃了。
> 本课程的价值主张就是：**不是 AI 不行，是你没给它足够的约束和材料。**

## 五、他们会问什么（预判）

高频提问及应对策略详见 `03-instructor-guide/classroom-faq.md`，此处列出预判：

| 提问 | 出现概率 | 策略 |
|---|:---:|---|
| 它会不会取代我的工作 | 极高 | 正面回答，30 秒，引到寄语 |
| 生成的内容能直接发出去吗 | 极高 | 不能，引到人工检查清单 |
| 公司的资料能不能传上去 | 高 | 引到 SECURITY.md 的红线清单 |
| 它会不会记住我上传的东西 | 高 | 引到隐私判断原则，不展开技术细节 |
| 提示词是不是有固定模板 | 高 | 有结构没有万能模板，引到 06-prompts |
| 为什么要它先提问，直接说不行吗 | 中 | 这是全课重点，展开讲 |
| 它算错了怎么办 | 中 | 数字必须人工核对，引到检查清单 |
| 和 ChatGPT / 其他工具有什么区别 | 中 | 30 秒带过，不做评测 |
| 我不会写提示词怎么办 | 中 | 就用 06-prompts/01 那一段，照抄 |
| 能处理多少字 / 多大文件 | 低 | 不展开，说"复杂任务要拆分" |

## 六、教学语言约定

| 原则 | 说明 |
|---|---|
| **用动作，不用名词** | 说"让它先提问"，不说"采用交互式需求澄清策略" |
| **用具体，不用抽象** | 说"把这 5 个数字核对一遍"，不说"进行数据校验" |
| **用第二人称** | 说"你需要告诉它"，不说"用户应当提供" |
| **一页一件事** | 一页 PPT 只讲一个知识点或一个操作步骤 |
| **先说结论** | 每页第一行就是结论，后面才是解释 |
| **给可复制的东西** | 每讲一个方法，配一段可以直接抄走的提示词 |

## 七、不适合本课程的对象

以下人群**不是**本课程的目标，请另行安排：

- 已经熟练使用 WorkBuddy 的老员工（内容过浅）
- 需要做二次开发、集成、自动化脚本的技术人员（内容不对口）
- 需要学习特定行业深度应用的专业岗（本课案例为通用办公场景）
- 只想了解 AI 趋势、不打算动手的管理层（建议只听第一、二、八章）
