# 学习成果

> 本文档定义"学完了"的标准。它同时是**学员自检表**和**培训效果验收表**。

---

## 一、核心成果：一个完整闭环

培训结束后，学员应能够理解并复现以下闭环：

```
提出任务
  → 让 WorkBuddy 补充提问
    → 回答关键问题
      → 获得可执行方案
        → 准备并上传附件
          → 分步骤执行任务
            → 查看生成结果
              → 提出修改要求
                → 人工检查
                  → 导出最终文件
```

**自检问题：** 不看资料，你能按顺序说出这 10 步吗？至少能说出 7 步。

---

## 二、十二项具体能力

| # | 能力 | 达标标准 | 自检 |
|:---:|---|---|:---:|
| 1 | **如何创建任务** | 能新建任务并写出第一句有效描述 | ☐ |
| 2 | **如何描述任务目标** | 描述中包含：背景、目标、对象、交付物 | ☐ |
| 3 | **不知道怎么描述时，如何要求先提问** | 能写出或复制"请先以提问的方式帮我明确" | ☐ |
| 4 | **如何告诉它最终需要哪些文件** | 能列出文件数量、名称、格式（docx/xlsx/pptx） | ☐ |
| 5 | **如何上传原始材料和模板** | 能区分"原始材料"和"模板"，并分别说明用途 | ☐ |
| 6 | **如何要求其不要虚构内容** | 能写出"只使用原始材料中的信息，不得虚构" | ☐ |
| 7 | **如何要求先输出方案再执行** | 能写出"在我确认方案之前，不要开始生成最终文件" | ☐ |
| 8 | **如何拆分复杂任务** | 面对 5 类交付物，能排出执行顺序而非一次全要 | ☐ |
| 9 | **如何根据初稿继续修改** | 修改要求具体到"哪一段、改成什么"，而非"再优化一下" | ☐ |
| 10 | **如何检查数字、日期、人名和结论** | 能说出这四类是必查项，并知道去哪核对 | ☐ |
| 11 | **哪些信息不能上传** | 能说出至少 3 类禁止上传的材料 | ☐ |
| 12 | **如何从 GitHub 下载完整案例并自行复现** | 能找到仓库、下载材料、跑通会议纪要案例 | ☐ |

**达标线：** 12 项中至少 10 项打勾。第 3、6、7、10 项为必过项。

## 三、三句话（能复述其一即算记住）

### 核心信息一 · 理解本质

> 使用 WorkBuddy 的第一步，不是寻找一个万能提示词，而是看清自己真正要完成什么工作。

### 核心信息二 · 提升效率

> AI 最有价值的地方，不是替你跳过思考，而是帮助你更快完成任务拆解、材料整理和成果制作。

### 核心信息三 · 面向未来

> 面向未来的工作能力，是能够与 AI 协作，同时保留自己的判断、责任和创造力。

## 四、三个核心动作（带走就够用）

如果学员什么都记不住，至少记住这三件事：

### 动作一：先让它提问

```
我想完成 [任务]，但还没完全想清楚。
请不要立即生成最终文件，请先以提问的方式帮我明确需求。
```

### 动作二：先要方案，再要文件

```
信息足够后，请先生成一份可执行方案。
在我确认方案之前，不要开始生成最终文件。
```

### 动作三：拿到结果先查四样

```
数字  → 和原始表格对得上吗
日期  → 年月日有没有串
人名  → 谁负责有没有搞反
结论  → 是原文说的，还是它自己推的
```

## 五、分层成果（不同学员的合理预期）

| 学员类型 | 培训后合理预期 | 不应期待 |
|---|---|---|
| **完全零基础，从没用过任何 AI** | 知道这个工具存在、大致能干什么、下次遇到整理类工作会想起它 | 立刻独立完成复现 |
| **用过 AI 聊天工具，但只用来问问题** | 理解"任务型"和"问答型"的区别，能照抄提示词跑通一次 | 自己写出高质量提示词 |
| **用过 AI 处理过文档，但结果不满意** | 找到之前失败的原因（没给材料 / 没给约束 / 一次要太多），能改进 | — |
| **已有一定使用经验** | 拿走一套可复用的流程规范和检查清单 | 学到新的技术知识 |

> 讲师注意：一场培训里四类人都有。**内容按第二类设计，语言按第一类打磨，材料按第四类准备。**

## 六、课后 7 天验收指标

| 指标 | 目标值 | 说明 |
|---|:---:|---|
| GitHub 仓库访问人数 | ≥ 学员数 × 30% | 说明"可复现"目标达成 |
| 材料下载次数 | ≥ 5 次 | 说明有人真的动手了 |
| 学员产出的 AI 文档数 | ≥ 3 份 | 说明进入实际工作流 |
| 关于"能不能上传"的咨询 | ≥ 1 次 | 说明隐私意识建立了 |

**如果 7 天内仓库零访问：** 第 1 优先级目标未达成。
排查方向：二维码是否清晰？第 45 页停留是否足够？README 第一屏是否劝退？

---

## 七、明确不承诺的成果

本课程 **不承诺** 学员在 60 分钟后能够：

- ❌ 写出适用于任何场景的万能提示词
- ❌ 完全不做人工检查就使用 AI 生成的文档
- ❌ 处理需要专业判断的分析工作（法务、财务、合规结论）
- ❌ 独立完成 PPT 的视觉设计
- ❌ 解决 AI 生成内容中的所有事实错误

**这些不是能力问题，是边界问题。** 课程会明确告诉学员这些边界在哪。
