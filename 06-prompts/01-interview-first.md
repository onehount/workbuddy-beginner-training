# 提示词 01 · 先提问，再形成方案

> **这是全课程最重要的一份提示词。** 如果只抄一份，抄这份。

| 项 | 内容 |
|---|---|
| **使用时机** | 任务刚开始，你还没完全想清楚要什么 |
| **输入文件** | 无（此步不需要上传任何附件） |
| **输出** | 一组澄清问题 → 你回答 → 一份可执行方案 |
| **下一步** | 确认方案后，进入 `02-execution-plan.md` |
| **确认节点** | ⚠️ 必须由你确认方案，它才能开始生成文件 |

---

## 可复制提示词

```text
我需要完成一次市场部门月度工作复盘，但目前还没有完全想清楚具体应该准备哪些材料、执行哪些步骤和生成哪些成果。

请不要立即生成最终文件。

请先以提问的方式帮助我明确以下内容：
1. 任务背景和最终目标；
2. 使用对象；
3. 已有材料；
4. 需要生成的文件；
5. 文件格式；
6. 时间要求；
7. 内容限制；
8. 数据口径；
9. 需要人工确认的事项；
10. 验收标准。

请每次提出数量适中的问题。

当信息足够后，请先生成一份可执行方案。方案应包括任务顺序、输入文件、每一步输出、人工确认节点、最终交付物和风险检查项。

在我确认方案之前，不要开始生成最终文件。
```

---

## 为什么这样写

| 这一句 | 在防什么 |
|---|---|
| `请不要立即生成最终文件` | 防止它跳过澄清直接输出一堆没用的东西 |
| `请先以提问的方式` | 把主动权交给它，让它替你想"还缺什么" |
| 十个编号项 | 给它一张检查表，避免它只问两句就说"我明白了" |
| `每次提出数量适中的问题` | 防止一次抛 30 个问题把你劝退 |
| `方案应包括…人工确认节点` | 强制它把"哪里需要你拍板"提前标出来 |
| `在我确认方案之前，不要开始生成` | 最后一道闸门 |

## 换成你自己的任务

把第一段的任务名替换掉即可，后面十项**一个字都不用改**：

```text
我需要完成 ______，但目前还没有完全想清楚具体应该准备哪些材料、执行哪些步骤和生成哪些成果。
```

可替换的例子：

- 一次季度述职汇报
- 一份新产品上市宣传方案
- 一次部门年度预算整理
- 一份供应商年度评估报告
- 一次团队培训课程设计

## 预期它会问什么（青屿茶研案例）

实际运行时，它大致会问到这些。**提前想好答案，回答会快很多：**

| 它会问 | 本案例的答案 |
|---|---|
| 这次复盘的时间范围？ | 2026 年 7 月 |
| 汇报给谁看？ | 市场部内部 + 直属上级 |
| 手上已经有哪些材料？ | 会议原始记录、参会人员表、活动完成表、渠道数据表、个人工作记录 |
| 最终要几个文件？ | 5 个：会议纪要、工作总结、活动通知、分析报告、复盘 PPT |
| 分别要什么格式？ | 前四个 docx，最后一个 pptx |
| 有模板吗？ | 有，5 份模板都会上传 |
| 什么时候要？ | 8 月 3 日前 |
| 内容有什么限制？ | 只能用材料里的信息，不能编 |
| 转化率怎么算？ | 有效线索 ÷ 线索 × 100% |
| 哪些需要你确认？ | 待确认的负责人和截止日期 |
| 怎么算做完了？ | 数字对得上、责任人明确、格式符合模板 |

## 常见错误对照

### ❌ 错误示范

```text
帮我写一个市场部月度复盘。
```

**问题：** 它不知道你有什么材料、要什么格式、给谁看。它只能靠编。

### ❌ 错误示范

```text
根据附件生成会议纪要、工作总结、通知、分析报告和PPT，要求专业、详细、美观。
```

**问题：** 一次要五个文件 + 三个形容词约束。它会全部做一遍，而且每个都很浅。

### ✅ 正确示范

用上面那段完整提示词。**慢一步，快十步。**
