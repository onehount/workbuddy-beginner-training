# 提示词 08 · 人工复核清单

> **本课程的收尾。** 对应 PPT 第八章「检查、复现与寄语」。
> 前七份提示词教你怎么让它干活，这一份教你**怎么不被它坑**。

| 项 | 内容 |
|---|---|
| **使用时机** | 每一份文档生成之后，导出之前 |
| **输入** | 生成的文档 + 全部原始材料 |
| **输出** | 一份可签字的、你敢负责的文件 |

---

## 一、四查（必做，不可跳过）

无论什么文档，拿到手先查这四样：

### 1️⃣ 数字

| 查什么 | 怎么查 |
|---|---|
| 每个数字在源表格里能找到 | 逐个对，不要抽查 |
| 合计 = 各项相加 | 自己按一遍计算器 |
| 百分比的分母是对的 | 特别是"整体转化率"这类加权指标 |
| 单位没有搞错 | 万 / 千 / 元 / 人次 |
| 没有多出源材料里没有的数字 | 尤其是金额、成本、ROI |

**本案例必查值：** 583,000 · 4,710 · 1,744 · 37.0%

### 2️⃣ 日期

| 查什么 | 怎么查 |
|---|---|
| 年份对不对 | AI 经常写成去年或明年 |
| 月份对不对 | 7 月的复盘不要出现 6 月的活动 |
| 截止日期是未来时间 | 别出现"请于 7 月 20 日前提交"这种已过期的 |
| 时间逻辑不冲突 | 活动 7/12 结束，数据统计到 7/31，合理 |
| 「下月」指的是哪个月 | 明确写 8 月，不要写"下月" |

### 3️⃣ 人名

| 查什么 | 怎么查 |
|---|---|
| 名字与参会人员表一致 | 别出现表里没有的人 |
| 岗位与人员表一致 | 别把设计写成运营 |
| 责任人没有搞反 | A 的活别写到 B 头上 |
| 「完成 / 参与 / 协助」用对了 | 见提示词 04 的动词分寸表 |
| 待确认的负责人没有被自动填上 | 最容易出的错 |

### 4️⃣ 结论

| 查什么 | 怎么查 |
|---|---|
| 每条结论能找到原文出处 | 找不到的，删掉或降级为"讨论" |
| 「建议」没有被写成「决定」 | 逐条对纪要 |
| 「待确认」没有被写成确定的 | 逐条对纪要 |
| 没有超出数据支撑范围的推断 | "趋势""持续""增长"都是危险词 |
| 没有 AI 自己加的行业常识 | 表里没有的洞察，都要怀疑 |

## 二、让它自查（可复制提示词）

人工查之前，先让它自己过一遍，能省一半时间：

```text
请对你刚生成的文档做一次自检，逐项回答，不要笼统说"已检查"：

【数字】
1. 列出文档中出现的全部数字，标注每个数字来自哪个源文件、哪一行；
2. 指出其中有没有你计算得出、而非直接引用的数字，并写出算式；
3. 指出有没有源材料中找不到出处的数字。

【日期】
4. 列出文档中出现的全部日期，标注出处；
5. 指出有没有你推断出来的日期。

【人名】
6. 列出文档中出现的全部人名和对应职责，标注出处；
7. 指出有没有源材料未明确、由你指定的责任人。

【结论】
8. 列出文档中每一条结论性表述，标注它在源材料中的出处（第几段、谁说的）；
9. 指出哪些属于你的分析判断，而非源材料的直接陈述。

【虚构自查】
10. 明确列出：这份文档中有哪些内容是你补充的，而不是源材料里有的。

请如实回答。如果某项确实没有问题，也要写出核对过程，不要只写"无问题"。
```

> 💡 **第 10 项是关键。** 直接问"你有没有编造"，它通常会说没有。
> 问"你补充了哪些"，它会老实交代。

## 三、发现问题后的纠正话术

### 数字不对

```text
文档中第 ___ 处的数字 ___ 与源表格不符，源表格中为 ___。
请检查是否还有其他数字存在同样问题，列出全部不一致项后再统一修改。
```

### 出现了源材料里没有的内容

```text
第 ___ 段的内容在源材料中找不到出处。
请删除，不要改写后保留。
删除后请说明还有哪些内容存在同样问题。
```

### 把待确认写成了确定

```text
第 ___ 项在会议纪要中标注为「待确认事项」，但文档中写成了确定结论。
请改回"待确认"，并检查其余待确认事项是否有同样问题。
```

### 责任划分不准

```text
第 ___ 项的负责人与参会人员表不符 / 源材料未明确。
请对照参会人员表核对全部责任人，未明确的一律标注"待确认"。
```

## 四、导出前最后确认

- [ ] 四查全部完成，问题全部改完
- [ ] 改完之后**重新通读一遍**（改动可能引入新问题）
- [ ] 文件命名符合规范：`序号_内容名称_版本_日期.扩展名`
- [ ] 文件属性中的作者已修改，无个人信息残留
- [ ] 无修订痕迹、无批注残留
- [ ] 格式符合模板（字体、字号、编号、页眉页脚）
- [ ] 导出 PDF 后再看一遍（排版问题在 PDF 里更明显）

## 五、责任归属（本课程的态度）

> **AI 生成的文档，署名的人是你。**
>
> 它不会因为写错数字被批评，你会。
> 它不会因为把建议写成决定而承担后果，你会。
>
> 这不是对 AI 的不信任，这是职业习惯。
> 就像你不会把实习生写的第一版直接发给客户 —— 不是因为实习生不行，是因为**签字的人要负责**。

## 六、三个核心动作（带走版）

如果这堂课只记三件事：

```
① 先让它提问
   "请不要立即生成最终文件，请先以提问的方式帮我明确需求。"

② 先要方案，再要文件
   "在我确认方案之前，不要开始生成最终文件。"

③ 拿到结果先查四样
   数字 · 日期 · 人名 · 结论
```
