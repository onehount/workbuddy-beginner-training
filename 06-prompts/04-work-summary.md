# 提示词 04 · 个人工作总结

> **本课程第二重点案例。** 对应 PPT 第 31–33 页。

| 项 | 内容 |
|---|---|
| **使用时机** | 会议纪要已完成并人工核对 |
| **输入文件** | `06_市场专员个人工作记录.docx`<br>已确认的会议纪要<br>`04_市场活动完成情况.xlsx`<br>`08_月度工作总结模板.docx` |
| **输出** | 六段式个人工作总结 docx |
| **确认节点** | ⚠️ 个人成果 vs 团队成果的区分必须人工复核 |

---

## 可复制提示词

```text
请根据市场专员个人工作记录、会议纪要和活动完成情况，生成 7 月份个人工作总结。

请分为：
1. 本月已完成工作；
2. 主要成果；
3. 正在推进的工作；
4. 存在的问题；
5. 下月计划；
6. 需要支持的事项。

要求：
- 个人独立完成的事项可以使用"完成"；
- 团队共同完成的事项使用"参与"或"协助"；
- 不得将团队成果全部写成个人成果；
- 每项成果尽量对应具体活动或数据；
- 不加入原始材料无法支持的内容。
```

---

## 全课程最实用的一条：动词的分寸

这是新人**最容易吃亏**的地方，也是本页的教学重点。

| 你的实际角色 | 该用的动词 | ❌ 不该用 |
|---|---|---|
| 一个人从头做到尾 | 完成、负责、独立完成 | — |
| 团队做，你是主力 | 主导、牵头 | 完成 |
| 团队做，你出了力 | 参与、协助、配合 | 完成、负责 |
| 别人做，你提供了材料 | 支持、提供 | 参与、完成 |
| 别人做，你只是知情 | （不要写） | 任何动词 |

### 为什么这件事很重要

**写小了：** 你的贡献被埋没。
**写大了：** 后果严重得多 ——

- 领导会以为这块归你，下次直接派给你
- 同事看到会觉得你抢功，团队关系受损
- 一旦被追问细节答不上来，可信度归零

> 💡 **课堂上要说这句：**
> AI 不知道哪件事是你一个人干的。它只会把工作记录里所有事情都写成"完成"。
> **这一项，只能你自己改。**

## 六段式的正确写法

### 1. 本月已完成工作
按时间或重要性排序，每条一行。**要有动词分寸。**

```
✅ 独立完成夏日新品试饮活动的物料筹备与现场执行（7/5–7/12）
✅ 参与小红书达人种草活动的达人筛选与内容审核（7/8–7/25）
✅ 协助完成商场快闪活动的场地对接
```

### 2. 主要成果
**必须挂数字。** 没有数字的成果不叫成果。

```
✅ 夏日新品试饮活动累计触达线下门店客流 46,000 人次，产生线索 740 条，有效线索 333 条，转化率 45.0%
❌ 夏日新品试饮活动效果良好，反响热烈
```

### 3. 正在推进的工作
写清楚**进度**和**卡在哪**。

```
✅ 校园联名活动物料设计已完成 70%，等待合作方确认 Logo 使用规范后定稿
❌ 校园联名活动推进中
```

### 4. 存在的问题
**写问题，不写抱怨。** 问题要能对应到行动。

```
✅ 抖音渠道转化率 25.0%，为五个渠道最低，投放内容与目标人群匹配度需复核
❌ 抖音效果太差了
```

### 5. 下月计划
和会议纪要里的行动事项对齐。**别自己加戏。**

### 6. 需要支持的事项
**这一节别空着。** 空着等于"我什么都不需要"，下次就真的没人给你资源了。

```
✅ 抖音渠道优化需要设计同事支持 2 个工作日制作 A/B 测试素材
```

## 拿到总结后必查

- [ ] 每一条"完成"，确认真的是你一个人做的
- [ ] 每一个数字，与 `04_市场活动完成情况.xlsx` 和 `05_渠道数据.xlsx` 对得上
- [ ] 每一项成果，能追溯到具体活动
- [ ] 没有出现工作记录里没有的事情
- [ ] 「下月计划」与会议纪要的行动事项不冲突
- [ ] 「需要支持的事项」不为空

## 常见问题

**Q：它把所有事情都写成"完成"了**

```text
请重新检查每一条工作事项，对照个人工作记录和会议纪要判断：
- 记录中明确写明由我一人执行的，保留"完成"；
- 记录中出现了其他同事名字的，改为"参与"或"协助"；
- 无法判断的，列出来问我。
请说明你改了哪几条、依据是什么。
```

**Q：它编了工作记录里没有的成果**

```text
请为「主要成果」的每一条，标注它在个人工作记录或活动完成情况表中的出处。
找不到出处的，直接删除，不要改写保留。
```

**Q：写得太虚，全是形容词**

```text
请删除「效果良好」「反响热烈」「显著提升」这类没有数据支撑的评价性表述。
每一条成果必须包含至少一个来自数据表的具体数字。
```
