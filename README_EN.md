## What this is

A complete, open-source teaching kit for a **60-minute classroom session** aimed at new employees with **no programming background** and **no prior knowledge of AI agents**.

The course does not teach "which button to click". It answers three questions:

- **Essence** — WorkBuddy does not think *for* you. It converts your goals, materials and constraints into a sequence of executable tasks.
- **Efficiency** — Real efficiency is not generating more text at once. It is removing the mechanical labour in clarifying tasks, organising materials, repetitive formatting and file conversion.
- **Future** — Future work capability is not mastering one piece of software. It is the ability to define goals clearly, organise materials, verify results, and collaborate with AI.

## The core loop taught in this course

```
State the task
  → Ask WorkBuddy to interview you first
    → Answer the key questions
      → Receive an executable plan
        → Prepare and attach source files
          → Execute step by step
            → Review generated output
              → Request revisions
                → Human verification
                  → Export final files
```

**Step 2 is the one that matters most.** Most people fail because they skip it and demand the final file immediately.

## The demo case

**QINGYU TEA LAB — Marketing Department, July 2026 monthly review**

- 5 marketing campaigns, 5 channels, 6 meeting participants
- ~2,000-word raw meeting transcript
- 20–35 rows of channel performance data
- Deliverables: meeting minutes → personal work summary → campaign notice → data analysis report → 10–12 page review deck

Unified metric definition across the whole project:

```
Conversion Rate = Qualified Leads ÷ Total Leads × 100%
```

## Quick start

**As a learner:** open `09-student-guide/quick-start.md`, then follow `reproduction-guide.md`.

**As an instructor:** open `02-slides/workbuddy-beginner-training.pptx` and teach along with `03-instructor-guide/full-speaking-script.md`.

**To adapt it for your own company:** replace the materials under `04-demo-inputs/`, keep the prompt structures in `06-prompts/`, and run the privacy review in `11-quality-assurance/privacy-review.md`.
