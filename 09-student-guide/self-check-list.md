# 自检清单

> 完成每个提示词后，对照此清单确认质量。

## 通用检查（所有输出）

- [ ] 文件命名规范：`序号_内容名称_版本_日期.扩展名`
- [ ] 作者已修改为工作用途（无个人信息残留）
- [ ] 无修订痕迹、无批注残留
- [ ] 格式符合模板要求

## 会议纪要专项

- [ ] 会议基本信息完整（时间/地点/主持人/参会人/记录人）
- [ ] 4 条已确认决定逐条列出（见 case_data.DECISIONS）
- [ ] 6 项行动事项含负责人与截止日期（见 case_data.ACTIONS）
- [ ] 5 项待确认事项标记正确，未写入决定（见 case_data.PENDING）
- [ ] 整体转化率写为 **37.0%**（加权），不是 **41.8%**（算术平均）
- [ ] 所有数字能在源材料中找到出处

## 工作总结专项

- [ ] 动词分寸正确：完成 / 参与 / 协助
- [ ] 校园联名标为进行中（延期），不是已完成
- [ ] 不含团队成果冒充个人成果
- [ ] 下月计划与纪要中的行动事项一致

## 活动通知专项

- [ ] 仅包含已确认事项
- [ ] 不含任何待确认事项
- [ ] 含对象 / 任务 / 负责人 / 时间 / 反馈方式五要素
- [ ] 截止日期均为未来时间

## 分析报告专项

- [ ] 总曝光 **583,000** / 总线索 **4,710** / 有效线索 **1,744** / 转化率 **37.0%**
- [ ] 每条结论标注为【事实】/【判断】/【建议】
- [ ] 转化率口径说明清晰（加权 vs 算术平均）
- [ ] 不含预算 / 销售额 / 用户画像等无数据支撑的内容
- [ ] 抖音低转化高曝光的问题已指出并给出数据支撑的建议

## 月度复盘 PPT 专项

- [ ] 页数在 10–12 页之间
- [ ] 每页一个核心结论
- [ ] 数据页标明统计周期与口径
- [ ] 含独立寄语页
- [ ] 不覆盖文字（字号 ≥ 14pt）
