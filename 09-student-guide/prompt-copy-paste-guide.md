# 提示词复制使用指南

> 仓库 `06-prompts/` 中包含 8 份可直接复制使用的提示词。
> 每份都标注了「为什么这样写」和「常见错误」。

## 使用方法

1. 打开对应的 `.md` 文件
2. 找到「可复制提示词」代码块（以 ```text 或 ``` 开头）
3. 复制全文，粘贴到 WorkBuddy 对话框中
4. 根据你的实际情况修改方括号 `[ ]` 中的占位符

## 各提示词要点速查

### 01 先提问
- **核心**：「请先以提问方式帮我明确需求」，不要直接要文件
- **关键问题**：背景、目标、对象、材料、格式、时限、限制、口径
- **常见错误**：一次给太多信息导致 WB 跳过提问直接出方案

### 02 执行方案
- **核心**：先确认方案再执行，不要一步到位
- **输出**：任务顺序、每步输入输出、确认节点、交付物
- **常见错误**：方案太笼统（如「帮我整理一下」），缺少具体步骤

### 03 会议纪要
- **核心约束**：不得虚构发言、数字、决定
- **结构**：基本信息 → 讨论 → 决定 → 行动事项 → 待确认 → 下次安排
- **关键区分**：讨论 ≠ 决定 ≠ 待确认
- **输入**：原始记录 + 纪要模板

### 04 工作总结
- **动词分寸**：完成 / 参与 / 协助（三档，不可混用）
- **边界**：不把团队成果写成个人成果
- **输入**：个人工作记录 + 已完成的纪要

### 05 活动通知
- **原则**：仅含已确认事项，不含待确认项
- **要素**：对象、任务、负责人、时间节点、反馈方式
- **输入**：纪要中的行动事项

### 06 分析报告
- **三分法**：事实 / 判断 / 建议（每条结论必须标注类型）
- **口径陷阱**：整体转化率必须加权，不可算术平均
- **红线**：不虚构预算、销售额、用户画像等源材料没有的数据
- **输入**：渠道数据 Excel（含公式）

### 07 综合 PPT
- **流程**：先大纲 → 确认/修改 → 再生成
- **结构**：封面→目录→背景→活动→数据→决定→行动→待确认→结论→计划→寄语
- **输入**：纪要 + 总结 + 通知 + 分析报告（4 份）

### 08 人工复核
- **四查**：数字 / 日期 / 人名 / 结论
- **自查技巧**：问「你补充了哪些」（比问「有没有编造」更有效）
- **纠正话术**：精确指出位置 + 要求全面排查 + 统一修改
- **态度**：AI 不负责，你负责。就像实习生初稿不能直接发给客户。
