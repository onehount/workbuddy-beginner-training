# TC-06 · 纪要人工复核

> 提示词参考：`06-prompts/03-meeting-minutes.md`

| 属性 | 内容 |
|------|------|
| **输入** | 原始版纪要 + 全部源材料 |
| **输出** | 03_会议纪要_人工审核版.docx |

## 操作步骤

1. 对照原始记录逐条核查数字

2. 对照参会表核查人名和岗位

3. 对照活动表核查日期和状态

4. 特别检查：待确认事项是否被误写为决定

5. 发现问题用纠正话术要求统一修改

## 要点

- 这是闭环的最后一步，不可跳过

- 改完后重新通读一遍（改动可能引入新问题）

## 常见错误

- ⚠️ 只抽查不逐条对 → 漏掉隐蔽错误

- ⚠️ 改了一处就收工 → 同类错误可能有多处
