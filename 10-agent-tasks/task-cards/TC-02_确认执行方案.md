# TC-02 · 确认执行方案

> 提示词参考：`06-prompts/01-interview-first.md`

| 属性 | 内容 |
|------|------|
| **输入** | 需求澄清问答记录 |
| **输出** | 经确认的分步执行方案 |

## 操作步骤

1. 审阅 WB 返回的方案：任务顺序、输入、输出、确认节点

2. 调整不合理的地方（如步骤顺序、遗漏的材料）

3. 口头或文字确认：「方案 OK，开始执行」

## 要点

- 方案是控制点，确认后才能生成文件

- 可以要求 WB 先出某一歩的输出看看质量

## 常见错误

- ⚠️ 没仔细看方案就确认 → 后面返工量大

- ⚠️ 方案太粗（只有 3 步）→ 拆细到 6–8 步
