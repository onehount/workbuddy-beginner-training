# TC-07 · 生成工作总结

> 提示词参考：`06-prompts/04-work-summary.md`

| 属性 | 内容 |
|------|------|
| **输入** | 06_个人工作记录.docx + 已审核纪要 |
| **输出** | 04_工作总结.docx |

## 操作步骤

1. 上传个人工作记录

2. 上传已审核的会议纪要（作为参考）

3. 粘贴提示词 04，强调动词分寸（完成/参与/协助）

4. 生成后检查校园联名是否标为延期

## 要点

- 苏眠是主角，视角是第一人称

- 团队成果不能写成个人成果

## 常见错误

- ⚠️ 所有工作都写成「完成」 → 应区分参与/协助

- ⚠️ 校园联名写成已完成 → 实际因 Logo 规范延期
