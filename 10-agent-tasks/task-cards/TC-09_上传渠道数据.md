# TC-09 · 上传渠道数据

> 提示词参考：`06-prompts/06-analysis-report.md`

| 属性 | 内容 |
|------|------|
| **输入** | 05_渠道曝光与线索数据.xlsx |
| **输出** | 数据已加载的分析上下文 |

## 操作步骤

1. 上传渠道数据 Excel 文件

2. 让 WB 先读取并概述数据结构（3 个 sheet）

3. 确认 WB 理解了周度明细 / 渠道汇总 / 数据字典

## 要点

- Excel 含公式，WB 应读取计算后的值而非自己重算

- 数据字典 sheet 定义了口径

## 常见错误

- ⚠️ WB 忽略了公式直接读原始值 → 数字可能不对

- ⚠️ 没让 WB 先确认数据结构就开始分析 → 方向偏差
