# TC-11 · 分析报告复核

> 提示词参考：`06-prompts/06-analysis-report.md`

| 属性 | 内容 |
|------|------|
| **输入** | 原始版分析报告 + 渠道数据 Excel |
| **输出** | 复核通过的分析报告 |

## 操作步骤

1. 逐个数字与 Excel 表格交叉验证

2. 检查每条「建议」是否有数据支撑

3. 检查是否有超出数据范围的推断（如趋势预测）

4. 用提示词 08 的自检话术让 WB 自查

## 要点

- 分析报告的错误比纪要更隐蔽（看起来很专业）

- 「趋势」「持续」「增长」都是危险词

## 常见错误

- ⚠️ 被专业术语唬住没仔细查数字 → 签字风险

- ⚠️ 忽略了数据来源说明 → 口径不清
