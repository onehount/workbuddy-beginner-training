# TC-18 · 终稿导出与归档

> 提示词参考：`06-prompts/08-review-checklist.md`

| 属性 | 内容 |
|------|------|
| **输入** | 全部复核通过的文档 |
| **输出** | 可签字的终稿包 |

## 操作步骤

1. 最后一次通读（改动可能引入新问题）

2. 检查文件命名、作者、格式

3. 导出 PDF 版本存档

4. 按项目归档结构保存

## 要点

- 归档是职业习惯的一部分

- 好的归档让你三个月后还能找到文件

## 常见错误

- ⚠️ 改完没重读 → 新问题没被发现

- ⚠️ 命名不规范 → 后来找不到文件
