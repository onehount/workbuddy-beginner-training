# TC-03 · 上传纪要材料

> 提示词参考：`06-prompts/03-meeting-minutes.md`

| 属性 | 内容 |
|------|------|
| **输入** | 02_会议原始记录.docx + 07_会议纪要模板.docx |
| **输出** | 材料已加载的任务上下文 |

## 操作步骤

1. 上传原始记录文件

2. 上传纪要模板文件

3. 粘贴提示词 03 的约束部分（不得虚构、区分三类）

## 要点

- 模板决定结构，原始记录决定内容

- 两个文件都要上传，WB 才知道格式要求

## 常见错误

- ⚠️ 只上传原始记录没传模板 → 格式不符合要求

- ⚠️ 忘了加「不得虚构」约束 → 出现编造内容
