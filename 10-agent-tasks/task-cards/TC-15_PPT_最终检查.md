# TC-15 · PPT 最终检查

> 提示词参考：`06-prompts/07-presentation.md`

| 属性 | 内容 |
|------|------|
| **输入** | PPT 初稿 + 4 份源文档 |
| **输出** | 可演示的终稿 PPT |

## 操作步骤

1. 逐页核对 PPT 内容与源文档的一致性

2. 检查数字（特别是转化率 37.0%）

3. 检查人名（6 人名单）

4. 全屏预览一遍排版效果

5. 导出 PDF 再看一遍（PDF 更容易发现排版问题）

## 要点

- PDF 预览是发现排版问题的好方法

- 演示前至少完整过一遍

## 常见错误

- ⚠️ 只在编辑视图看过 → 演示模式可能有意外

- ⚠️ 没导出 PDF 检查 → 打印时才发现问题
