# TC-16 · 执行四查——数字

> 提示词参考：`06-prompts/08-review-checklist.md`

| 属性 | 内容 |
|------|------|
| **输入** | 任意生成文档 + 对应源数据表 |
| **输出** | 数字核验报告 |

## 操作步骤

1. 列出文档中出现的全部数字

2. 逐个在源表中查找出处

3. 验证合计值（手动或用计算器）

4. 标记找不到出处的数字

## 要点

- 数字错误是最容易被发现的，也是最容易修复的

- 合计值必须手算验证

## 常见错误

- ⚠️ 只抽查不逐个对 → 可能漏掉错误

- ⚠️ 信任 AI 的计算能力 → 它也会算错
