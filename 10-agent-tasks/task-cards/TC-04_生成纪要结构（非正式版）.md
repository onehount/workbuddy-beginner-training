# TC-04 · 生成纪要结构（非正式版）

> 提示词参考：`06-prompts/03-meeting-minutes.md`

| 属性 | 内容 |
|------|------|
| **输入** | 已加载材料的上下文 |
| **输出** | 纪要结构草案 + 待确认事项列表 |

## 操作步骤

1. 要求 WB 先输出纪要结构（六大部分标题 + 每部分要点）

2. 要求同时列出所有待确认事项

3. 逐一核对：待确认事项是否与原始记录一致

## 要点

- 先结构后正文，是控制质量的关键节奏

- 待确认事项是最容易出错的部分

## 常见错误

- ⚠️ 直接要求生成正式文档 → 无法中途纠错

- ⚠️ 待确认事项被漏掉或被混入决定
